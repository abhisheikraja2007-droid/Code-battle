A high-octane competitive programming contest portal and battle registration arena built for the **Creatathon Hackathon**.

---

## 📌 Features
- **Live Battle Arena UI**: Futuristic dark theme with glowing neon accents, live challenge registration, and timer countdowns.
- **Participant Onboarding**: Interactive multi-step team and solo registration forms with client-side validation.
- **Rules & Track Breakdown**: Clear categorization of algorithmic challenges, web dev sprints, and speed debugging rounds.
- **Leaderboard Previews**: Dynamic live standing simulations and event schedule guides.

---

## 📂 Project Structure
```text
codebattle/
```

## 🚀 Running Locally
Simply open `index.html` in any modern web browser or serve via:
```bash
npx serve .
```
